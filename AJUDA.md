# Ajuda - Site Bicho & Cia (Fase 1)

Site estático em HTML puro (sem CSS e sem JavaScript), criado para a Fase 1 do projeto da disciplina.

## Páginas
| Arquivo | Funcionalidade |
|---|---|
| `index.html` | Página inicial: apresentação do petshop e atalhos. |
| `produtos.html` | 3 categorias (Cães, Gatos, Acessórios), 2 produtos cada, com foto, descrição e valor. |
| `servicos.html` | Tabela de serviços com descrição, valor e indicação de tele-busca. |
| `contato.html` | Endereço, telefone, e-mail e horários. |

## Estrutura de cada página
- **Cabeçalho (`header`)**: nome, informações do petshop e menu de navegação.
- **Corpo (`main`)**: conteúdo da página.
- **Rodapé (`footer`)**: links de navegação, contato e autoria.

## Como usar
1. Abra `index.html` no navegador, ou acesse o link do GitHub Pages.
2. Use o menu no topo (ou no rodapé) para navegar entre as páginas.

## Imagens
Ficam na pasta `imagens/`. Os arquivos `.svg` são ilustrações de exemplo; para usar fotos reais, coloque-as na pasta e atualize o atributo `src` das tags `<img>` em `produtos.html`.

## Publicação (GitHub Pages)
Settings > Pages > Source: "Deploy from a branch" > branch `main`, pasta `/ (root)`.
